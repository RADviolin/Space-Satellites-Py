# Space-Satellites-Py

This is my final project for a Python class. I want to:

- Add satellites to a 2D diagram of Earth and view their orbital path, adjust speeds and locations, and show positioning.
- I will also try to use Matplotlib and evaluate/display historic close approaches.
- I want to look at objects that pass within a chosen distance threshold.

For simplicity, I'm considering the satellite to be a circle and using example values: orbital radius = 8500 km
angle = 120

and basic trig concepts: 
x = r cos(theta)



y = r sin(theta)


- r = distance from Earth's center
- theta = satellite's angle around Earth
- x and y = satellite's position
