For simplicity, I'm considering the satellite to be a circle and using example values: orbital_radius = 8500 (km)
angle = 120

and basic trig concepts: \[
x = r\cos(\theta)
\]

\[
y = r\sin(\theta)
\]

- r = distance from Earth's center
- theta = satellite's angle around Earth
- x and y = satellite's position
